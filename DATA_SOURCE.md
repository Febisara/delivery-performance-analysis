# Data source

* Dataset: Brazilian E-Commerce Public Dataset by Olist
* Dataset owner: olistbr
* Source URL: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
* Licence: https://creativecommons.org/licenses/by-nc-sa/4.0/
* Scope: Historical Brazilian marketplace data from 2016–2018.
* Files used: olist\_orders\_dataset.csv and olist\_customers\_dataset.csv
* Location: data/raw/
* The raw CSV files have not been edited.



The inspected files contained 99,441 order rows and 99,441 customer rows.
The analysis is an independent exercise, not work commissioned by Olist.
